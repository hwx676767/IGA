# 校园小卖部：场景与对话规划

## 游戏定位

玩家以小学、初中或高中的学生身份经营校园小卖部。在一天的若干时段中切换校园地点，和四个派系接触、完成委托、建立好感，再把获得的情报与渠道用于下一轮交易和收藏。

主循环为：**选择地点 → 对话/接委托 → 获得好感与情报 → 进货或摆摊 → 结算事件 → 解锁下一层派系能力与收藏品**。

## 当前场景的必要调整

`SampleScene` 内的九张背景目前都位于 `(0, 0, 0)`，排序均为 `0`；它们会相互遮挡，运行时无法作为九个地点使用。

已加入的 `CampusGameBootstrap` 会在运行时只激活当前地点的背景；对话 UI 已直接保存到场景中，场景内不生成 NPC 对象。

## 地点安排

| 地点 | 主派系 / 立绘 | 叙事职责 | 解锁前后变化 |
| --- | --- | --- | --- |
| 图书馆 | 林知远，书呆子 | 学习资料、合规交易、学业委托 | 高好感后可求情，学霸系物品减价 |
| 操场 | 周劲，体育生 | 体育补给、球具、摆摊人流 | 解锁专属摆摊点，人流量翻倍 |
| 食堂 | 黎莓，校园潮人 | 零食、潮流货、每日流行风向 | 解锁需求预测和稀有货预告 |
| 美术教室 | 夏澄，二次元狂热者 | 收藏品评估、同人/漫展周边 | 解锁高端收藏渠道和复制机会 |
| 教室（小学） | 学霸系 | 日常学习委托与绝版笔记线索 | 从地图的“教室”入口进入；对应课本、文具需求 |
| 教室（初中） | 潮人系 | 手链、指尖陀螺、社团传闻 | 从地图的“教室”入口进入；中等风险委托 |
| 教室（高中） | 二次元系 | 掌机、模型、展会情报 | 从地图的“教室”入口进入；高价值收藏委托 |
| 宿舍 | 二次元系 | 夜间整理库存、展示收藏、触发角色私聊 | 解锁展示柜后陈列稀有物 |
| 厕所 | 潮人系 | 隐蔽交易与违禁品传闻 | 仅在潮人好感达到门槛后开放高风险货源 |

## 角色与玩家立绘

四位固定派系联系人使用现有的 `NPC书呆子`、`NPC体育生`、`NPC非主流`、`NPC二刺螈` 立绘。玩家身份可在小学/初中/高中之间切换；当前原型不显示玩家立绘，只在对话开始时显示联系人立绘。

当前原型对每个联系人配置三句“初见”对话。后续每个角色应至少拥有以下对话组：

1. 初见：介绍派系交易边界与该地点规则。
2. 日常：由当天需求、持有物、玩家阶段和好感决定。
3. 委托：提出明确目标、奖励、风险和截止时间。
4. 结算：成功、失败、拒绝或违规后的不同结果。
5. 解锁：派系机制与红色收藏品的专属演出。

## 对话状态设计

对话不直接改写交易数值，而是发送结果给未来的交易系统：`好感变化`、`解锁标签`、`委托状态`、`情报`、`违规热度`。这样剧情和买卖系统可以独立迭代。

建议对话条件使用以下字段：

- `playerStage`：小学 / 初中 / 高中。
- `factionFavor`：四个派系各自的好感值。
- `questState`：未接取、进行中、完成、失败。
- `ownedItems`：持有物和收藏品。
- `heat`：违规热度；影响老师检查、骚扰和处罚事件。
- `dayPeriod`：早课、午休、放学、夜间。

## 剧情推进建议

第一天以食堂的低风险零食交易作为教学。第二天开放图书馆与操场，让玩家在“稳定学业线”和“快速体育线”间选择。第三天由美术教室引入收藏价值；潮人好感达到门槛后，厕所才出现高收益、高热度的隐蔽货源。四派系都达到阶段性好感后，玩家选择经营方向并冲刺对应结局：好学生、操场霸主、校园潮流或大收藏家。

## 已实现的剧情对话流程

`CampusGameBootstrap` 已将以上骨架实现为五天的可玩对话流程：

| 天数 | 主要剧情触发地点 | 剧情内容 |
| --- | --- | --- |
| 第一天 | 食堂 | 认识黎莓，在“合规零食试卖”与“打听潮流货源”间作出首个选择。 |
| 第二天 | 图书馆、操场 | 分别认识林知远和周劲，接触学习资料线与校队补给线。 |
| 第三天 | 美术教室、三间教室 | 认识夏澄；通过年级教室补足阶段需求与收藏叙事。 |
| 第四天 | 宿舍与四派系地点 | 四派系回访，对情报、信誉、保镖和展示柜线索作出选择。 |
| 第五天 | 任意地点 | 与任意派系联系人对话，查看四条经营结局预览。 |

非教室地点的选择只记录派系好感、委托/情报线索与结局资格。教室是当前唯一的交易场景：顾客会提出商品需求，出售正确库存后会扣除库存并增加金钱。

所有地点均可自由前往；天数只决定各地点会触发初见、委托或结局等哪一段剧情。运行操作：点击右下角“交谈”开启当前地点对话；使用“继续”和回应按钮推进；“结束本日”进入下一天；A/D 或左右方向键切换地点；Esc 关闭对话。

## 当前 UI 布局

- 顶部：左侧保留日期与地点；右上角固定显示 `金钱 ¥ 0`，等待交易系统接入数值。
- 顶部中间：小学/初中/高中与角色切换归入 `DEBUG · 学段测试` 面板；按 F1 可临时隐藏，后续正式版可整体移除。
- 场景：不再常驻显示派系角色，背景保持干净。
- 交谈：右下角“交谈”按钮直接在场景上显示对话面板（名称、台词、选择与继续按钮）。场景中不放 NPC 或玩家对象；只有对话面板右侧的 `NpcPortrait` 会显示当前联系人立绘。台词不使用旁白介绍。
- 地图：右下角“地图”按钮（快捷键 M）打开校园区域；所有地点可前往。地图只有一个“教室”入口，会按当前小学/初中/高中学段进入对应教室，不显示学段名称。
- 教室交易：进入教室后直接显示 `ClassroomTradePanel`；顾客区只保留会刷新出现的学生立绘。右侧的 `BagBack.png` 小卖铺面板内使用 Scroll View 展示 2×3 商品图片，不显示商品卡片背景或文字；鼠标悬停商品会放大图片，并在鼠标下方显示名称。

UI 由编辑器菜单 `Tools > Campus Shop > Generate UI In SampleScene` 生成并保存到 `SampleScene` 层级，运行时不会创建 Canvas 或按钮。生成后可以直接在 Hierarchy 中调整 `CampusGameUI` 及其所有子对象的布局和美术。
