# 交易系统框架（待确认，不实现）

## 目标

让每次买卖都由“地点、派系、玩家阶段、需求、风险、收藏价值”共同决定，而不是单纯以固定价格买进卖出。

## 一次交易的流程

1. 每日刷新：地点客流、学生需求、稀有货、老师检查和派系情报。
2. 进货：玩家从派系渠道、普通货源或特殊事件中选择商品。
3. 摆摊：在当前地点选择商品与售价；操场摆摊点是体育生高好感解锁内容。
4. 顾客判定：根据需求匹配、价格接受度、派系关系、热度和随机事件决定成交、砍价、赖账或举报。
5. 结算：变化包括金钱、库存、好感、违规热度、委托进度和收藏图鉴。

## 数据对象

| 对象 | 必要字段 | 说明 |
| --- | --- | --- |
| ItemDefinition | id、名称、类别、阶段、基础价、稀有度、合法性、所属派系、保值期 | 静态配置；同一物品只定义一次 |
| InventoryStack | itemId、数量、进货成本、获得日期 | 玩家库存；成本按批次保存 |
| Demand | itemTag、地点、阶段、强度、有效时段 | 每日动态需求，不必绑定某个具体 NPC |
| CustomerProfile | 阶段、偏好标签、预算、派系、耐心、风险偏好 | 用于成交和砍价判定 |
| FactionState | 好感、解锁标签、专属折扣、已完成委托 | 四派系持久状态 |
| Quest | 条件、期限、奖励、失败后果、关联派系 | 由对话系统创建或推进 |
| MarketEvent | 触发条件、持续时间、价格/需求/风险修正 | 如老师检查、稀有货预告、校队比赛 |

## 类别与阶段

- 类别：食物、工艺品、文具、潮流、文件、违反校规、收藏品。
- 小学：辣条、薯片、可乐、乐高、铅笔盒、卡牌、漫画书等。
- 初中：泡面、牛肉干、手办、遥控车、修正带、手链、激光笔等。
- 高中：咖啡、茶包、能量饮料、高达、钢笔、Switch、球拍等。
- 红色收藏品不参与普通消耗性交易，作为长期里程碑奖励和能力解锁。

## 定价规则

建议把价格固定为可解释的乘法链，而非散落在代码中的特例：

`成交价 = 基础价 × 稀有度 × 地点需求 × 阶段匹配 × 派系好感 × 事件修正 × 玩家售价系数`

其中：

- 买入价使用渠道折扣；学霸卡对学霸系 -20%，体育冠军收藏对体育系进货 -30%。
- 卖出价受潮人夹克影响，潮流/违禁类 +50%。
- 二次元典藏手办使收藏品不贬值，并开放展示柜的叠加效果。
- 高于顾客接受价时进入砍价、放弃或赖账；违规货还要叠加热度与检查风险。

## 四派系的系统效果

| 派系 | 好感奖励 | 终极收藏奖励 |
| --- | --- | --- |
| 学霸 | 代做作业、复习、违规求情 | 成绩拉满、学业处罚清零、学霸货 -20% |
| 体育生 | 保镖，减少骚扰/赖账，部分强制成交 | 保镖常驻、体育货进价 -30%、操场人流翻倍 |
| 潮人 | 需求预测、稀有货预告、隐藏委托 | 潮流/违禁卖价 +50%、高级货概率提高 |
| 二次元 | 高端收藏渠道、稀有物复制机会 | 收藏品永不贬值、展示柜与全部专属 buff |

## 需你确认的规则

1. 玩家每局是固定选定一个学段，还是允许像当前对话原型一样切换学段测试？正式玩法建议固定学段，并在周目/章节推进时升级。
2. “违反校规”是高风险可交易品，还是只作为剧情事件道具？建议保留交易，但用热度和处罚严格限制。
3. 是否允许玩家同时经营所有派系，还是最终只能选择一条结局线？建议前中期并行、终局主选一派。
4. 交易频率应为“每个时段一次摆摊”还是“每个地点可进行多次单笔买卖”？建议前者，以便事件和时间安排有意义。
5. 货币名称、初始资金、每日时段数、好感门槛以及红色藏品的获得条件尚未定义；这些确认后再实现数值与 UI。

## 实现边界

本阶段不创建交易代码、不改库存、不写价格数值。确认上述规则后，再按“数据配置 → 库存 → 刷新需求 → 单笔交易判定 → UI → 存档”的顺序实现，避免先做 UI 后返工核心规则。
