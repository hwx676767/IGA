# Mahou Circle — 如何游玩

## 首次设置（编辑器里生成场景 UI）
1. 等待脚本编译完成
2. 菜单 **Mahou Circle → 1. Reimport UI Sprites**
3. 菜单 **Mahou Circle → 2. Populate Forum Posts**
4. Hierarchy 中应出现 `MahouBrowser` → `Canvas`
5. Game 视口选 **2048×1536**，按 **Play**

## 录制主线（推荐）
1. **Mahou Circle**：逛 Announcements / Talk；打开帖子 `Anyone go to the latest meetup?`
2. 点粉色链接 **↗ https://renova.institute/** → 解锁并打开 ReNova（官网默认锁定）
3. **ReNova**：看 Home / About / Team / Contact，拼出员工账号
   - Contact → 用户名 `research`
   - About → 密码 `phase2`
4. ReNova → **LOG IN** 登录 → 进入 **Staff**
5. Staff 搜索关键词（如 `subject selection`）→ 点词条看详情，拼真相

## 备用线索
- 论坛搜索：`renova` / `central exchange` / `kamiyomi` / `stable frequency`
- Staff 报告关键词共 12 个（见游戏内 Progress）

## 截图
- 不要系统截 Game 缩小预览；Play 后按 **F12**（或菜单 Capture Screenshot）
