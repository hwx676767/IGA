# Heat Distortion — Scene Panel

Same workflow as **WindSystem** / **AirborneSand**.

## Open the panel

1. Menu: **Sand → Setup Heat Distortion (URP)** (once)
2. Hierarchy select **HeatSystem**
3. Tune in Inspector

Or: **Sand → Select Heat System**

## Inspector fields

| Field | Meaning |
|-------|---------|
| Enable Heat | On/Off |
| Distortion Strength | Warp amount |
| Noise Scale | Ripple size |
| Scroll Speed | Flow speed |
| Use Local Wind | Else follows WindManager |
| Depth / Height Mask | Limit haze to distance & height |

No need to open `PC_Renderer` for daily tweaks.
